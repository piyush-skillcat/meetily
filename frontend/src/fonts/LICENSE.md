# Bundled fonts

Shipped with the app so builds never need to reach Google Fonts.

- **Inter** (variable, Latin subset), by Rasmus Andersson: SIL Open Font License 1.1, https://github.com/rsms/inter
- **IBM Plex Mono** (400/500/600, Latin subset), by IBM: SIL Open Font License 1.1, https://github.com/IBM/plex

Files are the Latin-subset WOFF2 builds served by Google Fonts.
